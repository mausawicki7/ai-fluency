# Capstone — Stack & Conventions

Rules file for AI assistants working in `capstone/`.

## Stack

- Runtime: Node.js (LTS)
- Framework: React (Vite)
- Version control: Git, Conventional Commits

## Conventions

- **Commits** — Conventional Commits, imperative mood, present tense
  (e.g. `feat(capstone): add streaming chat interface`).
- **Code style** — 2-space indent, semicolons, single quotes.
- **Branching** — `main` is the trunk; feature work on short-lived branches
  (`feat/streaming-chat`) merged back.

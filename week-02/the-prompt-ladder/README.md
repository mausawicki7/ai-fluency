## Brief

Full brief: [brief.md](brief.md)

Start from a genuinely weak prompt, improve it across five versions (one
added layer each), compare real output at every step, and end with a
clean reusable prompt.

## What was delivered

- Baseline: real weak prompt Mau would've actually typed —
  "Haceme una web de autos que venda" — for Experiencia Elite.
- 6 runs total (baseline + 5 layered versions): objetivo claro → contexto
  real → audiencia definida → formato de salida → ejemplos de copy real.
- Honest "didn't help" moment: V4 (forcing a strict section-by-section
  output format) flattened the voice V3 had gained — turned specific
  copy back into generic consultant-speak ("Objetivo: conversión").
  Recovered in V5 by asking for the actual copy line per section instead
  of just its purpose.
- Final reusable prompt: works with placeholders for any event/track
  member, not just this one.

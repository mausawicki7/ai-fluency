Phase: Setup · Estimated hours: 3

Why it matters: AI-assisted development is the core skill of this track, and it starts with a working toolchain.

Brief:

    Install Node.js (LTS), Git, and your editor. Set up Claude Code in your terminal or Cursor as your IDE.
    Create your capstone GitHub repo: README stub, license, .gitignore , and a CLAUDE.md (or Cursor rules file) describing your stack and conventions.
    Make your first three commits in Conventional Commits format; your final Git history is evaluated.
    Ask your AI assistant to critique your README and apply one improvement.

Deliverable: Repo URL plus a screenshot of your AI assistant completing a task in your environment.

Evaluation criteria:

    Repo has README, license, and a CLAUDE.md or rules file
    At least three commits in Conventional Commits format
    Screenshot shows Claude Code or Cursor working

Linked resources:

    Claude Code docs: Overview (opens in a new tab) (account required): install paths for terminal, VS Code, and desktop.
    Cursor docs (opens in a new tab) (account required): the official reference if you pick Cursor.
    Conventional Commits 1.0.0 (opens in a new tab) : the commit format for the whole track, learnable in ten minutes.

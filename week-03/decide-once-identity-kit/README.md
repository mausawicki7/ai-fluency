# Decide Once: Build Your Identity Kit

**Track:** General AI Fluency
**Estimated workload:** 2h
**Phase:** Foundations

## Brief

Full brief: [brief.md](brief.md)

Type, palette, logo/favicon, and a two-line style note — decided once,
inherited by every page and case study.

## What was delivered

- Formalized the visual language already used in the
  [week-01 sitemap diagram](https://claude.ai/code/artifact/2a5466af-6bed-4a50-b821-bd67e0947217)
  instead of inventing a new one — same sage/pine "engineering pad" world,
  now the official identity.
- Considered reusing a real logo/palette Mau designed professionally for
  a political party (Nueva Generación Neuquina) — rejected: it's the
  client's brand, not his, using it would politicize a freelance
  portfolio with no connection to the claim, and its fonts (Gotham Bold,
  Delight Typeface) aren't free, which the brief requires.
- Type: IBM Plex Mono (heading) + IBM Plex Sans (body) — free, same
  family, technical rather than "landing page generic."
- Palette: `#24352B` main · `#1A2420` text · `#F7F8F0` background ·
  `#CC4B23` accent (one).
- Logo: "MS" monogram in Plex Mono, at three sizes (full name /
  monogram / 48px favicon).
- Full kit: [identity-kit artifact](https://claude.ai/code/artifact/85776021-1f23-4bac-bdb2-9b1bb87041fe).
